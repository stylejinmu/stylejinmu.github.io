Privacy Policy / 隐私权政策

爱你三千年 · AI Web Translation Assistant

最后更新：2026 年 5 月 25 日

本隐私权政策说明浏览器扩展「爱你三千年」（以下简称「本扩展」）如何处理与您相关的信息。 开发者（「我们」）不运营用于接收或存储用户数据的中央服务器。 使用本扩展即表示您同意本政策；若不同意，请卸载并停止使用。

1. 我们处理哪些信息

本扩展可能涉及以下类型的信息：

  • 本地配置信息：您填写的 API 地址、模型名称、API Key，以及默认源语言、目标语言、翻译风格等偏好。 这些信息保存在您设备上的浏览器本地存储（chrome.storage.local）中。
  • 待翻译的网页文本：当您主动发起翻译（包括划词翻译、整页翻译或右键菜单翻译）时， 本扩展会读取当前页面中需要翻译的可见文本，或您选中的文本。
  • 网页访问上下文：为实现翻译功能，本扩展需要在您浏览的网页中注入内容脚本并读取页面 DOM 文本。 我们不以收集、上传或分析您的浏览历史为目的。

本扩展不会向开发者服务器发送上述信息。我们也不收集姓名、邮箱、电话号码等账户信息（本扩展不提供独立账号注册）。

2. 我们如何使用这些信息

  • 保存您的 API 配置与偏好，以便下次使用时无需重复填写。
  • 在您点击翻译或触发右键菜单时，将待翻译文本发送至您自行配置的 OpenAI 兼容 API（请求路径为 {API 地址}/chat/completions），并展示返回的译文。
  • 在扩展界面中显示连接测试、错误提示与翻译进度等状态信息。

3. 信息的存储与保留

  • API 配置与偏好仅存储在您的浏览器本地，不会同步至我们的服务器。
  • 您可在扩展设置中修改或清空 API Key 等配置；卸载扩展后，本地数据是否保留取决于浏览器行为。
  • 翻译过程中的文本仅在功能执行期间于内存中使用，本扩展不会将其持久化保存到开发者侧。

4. 第三方服务

翻译请求由您选择的第三方 AI 服务提供商处理（例如 OpenAI 兼容接口的运营商）。 该等服务商如何收集、使用、保留和保护数据，受其各自隐私政策与服务条款约束，不在本扩展开发者控制范围内。 请在配置 API 前自行阅读并评估您所使用服务的隐私与安全措施。

本扩展本身不包含广告、分析追踪 SDK，也不向第三方出售您的个人信息。

5. 权限说明

为实现上述功能，本扩展声明以下浏览器权限：

  • storage：在本地保存设置与偏好。
  • contextMenus：提供选中文本的右键翻译入口。
  • activeTab：与当前活动标签页通信以执行翻译。
  • <all_urls>（主机权限）：在网页中注入脚本并读取待翻译文本。

请您知悉：网页内容可能包含个人或敏感信息。请勿在不可信页面或含机密信息的场景中使用翻译功能。

6. 您的选择与权利

  • 您可自主选择是否配置 API、是否发起翻译，以及使用哪家 API 服务商。
  • 您可随时在设置中更新或删除 API Key 与其他配置。
  • 您可随时卸载本扩展以停止数据处理。

7. 儿童隐私

本扩展不面向 13 周岁以下儿童。我们不会有意收集儿童的个人信息。

8. 政策变更

我们可能因功能更新或法律要求修订本政策。更新后的版本将发布于本页面并更新「最后更新」日期。 重大变更时，我们可能通过扩展更新说明或其他合理方式提示您。继续使用本扩展即视为接受修订后的政策。

Last updated: May 25, 2026

This Privacy Policy describes how the browser extension “爱你三千年” / “Love You Three Thousand Years” (the “Extension”) handles information related to you. The developer (“we”) does not operate a central server to receive or store user data. By using the Extension, you agree to this Policy. If you do not agree, please uninstall and stop using it.

1. Information We Process

The Extension may involve the following types of information:

  • Local configuration: API base URL, model name, API key, and preferences such as default source language, target language, and translation style. This is stored locally on your device via chrome.storage.local.
  • Web page text to be translated: When you actively start a translation (selection popup, full-page translation, or context menu), the Extension reads visible text on the current page or text you selected.
  • Page access context: To provide translation, the Extension injects content scripts and reads DOM text on pages you visit. We do not collect, upload, or analyze your browsing history for that purpose.

The Extension does not send the above information to the developer’s servers. We do not collect account details such as name, email, or phone number (the Extension has no standalone account registration).

2. How We Use Information

  • Store your API settings and preferences so you do not need to re-enter them each time.
  • When you translate, send text to the third-party OpenAI-compatible API you configure (at {API base URL}/chat/completions) and display the returned translation.
  • Show connection tests, errors, and translation progress in the Extension UI.

3. Storage and Retention

  • API settings and preferences are stored only in your browser locally, not on our servers.
  • You may update or clear your API key and other settings in the Extension. After uninstallation, whether local data remains depends on your browser.
  • Text processed during translation is used in memory for the operation; the developer does not persistently store it.

4. Third-Party Services

Translation requests are handled by the AI service provider you choose (e.g., an OpenAI-compatible API operator). How that provider collects, uses, retains, and protects data is governed by its own privacy policy and terms, outside the developer’s control. Please review the provider’s policies before configuring your API.

The Extension does not include ads, analytics tracking SDKs, or sale of personal information to third parties.

5. Permissions

The Extension requests the following browser permissions:

  • storage — save settings and preferences locally.
  • contextMenus — offer right-click translation for selected text.
  • activeTab — communicate with the active tab to run translation.
  • <all_urls> (host permission) — inject scripts and read text on web pages.

Web pages may contain personal or sensitive information. Use translation carefully on untrusted pages or where confidentiality matters.

6. Your Choices

  • You choose whether to configure an API, when to translate, and which provider to use.
  • You may update or delete your API key and other settings at any time.
  • You may uninstall the Extension at any time to stop processing.

7. Children’s Privacy

The Extension is not directed to children under 13. We do not knowingly collect children’s personal information.

8. Changes to This Policy

We may update this Policy for product or legal reasons. The revised version will be posted on this page with an updated “Last updated” date. For material changes, we may notify you through release notes or other reasonable means. Continued use means you accept the updated Policy.
